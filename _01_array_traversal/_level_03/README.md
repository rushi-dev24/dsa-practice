# Array Traversal – Level 03

This folder contains Java implementations of advanced-level array traversal and manipulation problems.

The focus of this level is to master array rotations, efficient shifting techniques, and segment-based transformations using optimized in-place logic.

---

## Problems Included

1. **InsertPosition**  
   Find the appropriate index to insert an element while maintaining array order.

2. **LeftRotate**  
   Implement left rotation of an array by `K` positions.

3. **ManualShifting**  
   Demonstrate manual element shifting logic for data repositioning.

4. **ReverseSubArray**  
   Reverse a specific segment or sub-array within a given array.

5. **RightRotate**  
   Implement right rotation of an array by `K` positions.

6. **SwapTwoSegments**  
   Swap two non-overlapping segments within the same array.

---

## Concepts Practiced

- Array Rotations (Left & Right)
- In-place Memory Manipulation
- Segment Reversal
- K-step Shifting Logic
- Index Mapping & Pointer Arithmetic
- Boundary Condition Handling

---

## Language Used

Java (Core Java only)

---

## Objective of This Level

- Master multi-step array transformations
- Implement algorithms with $O(1)$ auxiliary space complexity
- Transition from basic traversal to structural array modifications
- Prepare for complex problems involving cyclical properties
