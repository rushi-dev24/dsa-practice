# Array Traversal – Level 02

This folder contains Java implementations of intermediate-level array traversal problems.

The focus of this level is to strengthen loop control, nested traversal logic, and pattern observation using brute-force approaches.

---

## Problems Included

1. CheckDuplicates  
   Identify duplicate elements in an array.

2. CompareTwoArrays  
   Compare two arrays to check if they are equal.

3. CountPairs  
   Count valid pairs in an array based on a condition.

4. CountTriplets  
   Count valid triplets in an array.

5. LongestIncreasingSubArray  
   Find the longest continuous increasing subarray.

6. MajorityElement  
   Find the majority element in an array.

7. RemoveDuplicates  
   Remove duplicate elements from an array.

8. SubArraySum  
   Calculate sum of subarrays.

9. SubArrays  
   Print all possible subarrays.

---

## Concepts Practiced

- Array Traversal
- Nested Loops
- Subarray Generation
- Pair & Triplet Counting
- Duplicate Handling
- Majority Element Logic

---

## Language Used

Java (Core Java only)

---

## Objective of This Level

- Build strong fundamentals
- Improve brute-force problem solving
- Prepare for optimized approaches (Prefix Sum, Sliding Window, Hashing)
